An Agentic Harness for Interpreting SQL Data

Project Description
What: Build an AI-powered data analytics application where users can ask questions about a SQL database using normal language instead of writing SQL themselves.

The AI agent will plan how to answer the question, safely query the database, analyze the results, and return an explanation with tables or visualizations. The finished software is intended to be deployed and demonstrated within Telligen as a real-world AI analytics tool, rather than existing only as a classroom prototype.

Users: The primary users are:  Healthcare and business analysts Data engineers and software engineers Clinicians or healthcare professionals who need information from data Business users who understand their questions but may not know SQL  Students will work with Telligen employees and technical mentors to understand how these users interact with healthcare data in real-world environments.

Features: Natural-language data querying: Ask questions about a database without manually writing SQL.
Agentic SQL generation: The AI agent determines what information it needs and generates one or more SQL queries to answer the question.
Transparent results: Users can see the SQL, intermediate results, and supporting evidence behind an answer.
Analytics and visualization: The agent can use Python to calculate statistics and automatically create useful tables and charts.
Safe database access: The agent operates with read-only permissions and includes safeguards against unsafe or invalid SQL.

UseCases: An analyst asks, “How many diabetic patients had an ER visit within the last 12 months?” and the agent generates the appropriate SQL and explains the result.
A business user asks, “Which patient groups had the highest number of hospital visits this year?” without needing to understand the underlying database schema.
A user asks a more complicated question that requires information from several tables. The agent breaks the problem into smaller steps, runs multiple queries, and combines the results.
A user asks for a trend such as “Show hospital visits by month and explain whether they are increasing or decreasing.” The application generates the analysis and visualization automatically.
An engineer can inspect the SQL generated by the agent and verify where the answer came from.

Example: Sarah is a healthcare analyst at Telligen. She wants to understand whether patients with diabetes are visiting emergency departments more frequently than other patients.  Instead of manually exploring the database and writing several SQL queries, she types:  “Compare emergency department visits for diabetic and non-diabetic patients over the last year.”  The AI agent determines which database tables are needed, generates safe read-only SQL, runs the analysis, and returns the answer with the SQL, a short explanation, and a chart showing the difference between the two groups.

Project Elements: Significant Front-end components, Significant Back-end components, Significant data storage and data relationship needs, Significant Data analysis 

Technical Constraints: The project intentionally leaves some implementation decisions to the student team, but the expected stack is:

.Python for the AI agent, backend, and data analysis
.SQLite for the initial local synthetic healthcare database
.Python libraries such as Pandas and common visualization libraries
.An LLM/agent framework selected by the team after evaluating existing open-source options
.TypeScript/React may be used if the team builds a web interface
.Git-based source control and modern AI-assisted development tools

The team should build on a mature open-source agent framework rather than creating an entire agent framework from scratch.

The application must use read-only database access and publicly available synthetic healthcare data. No protected health information (PHI) will be used. 

Resources: Telligen will provide:

Technical mentorship from engineers and AI/data professionals
Healthcare domain knowledge and realistic analytics use cases
Guidance on what makes analytics useful and trustworthy in a production environment
Regular meetings with the student team for feedback and technical review
Guidance on AI-assisted software development, testing, security, and deployment
Access to appropriate AI development resources as needed for the project

Telligen is a healthcare technology company with a presence in the Des Moines area. Students will get hands-on, internship-style experience working with an industry engineering team on software intended for real-world use, rather than working only on a hypothetical academic project.

All healthcare data provided for the project will be public or synthetic.
